# EserPromo

Eser Promo e-ticaret projesi. Ürün, kategori, fiyat ve stok verileri Etkin / Birikim Promosyon API üzerinden senkronize edilecektir.

## Stack (plan)

- WordPress + WooCommerce
- Gece API senkronu (custom plugin)
- Güvenlik sıkılaştırma + Cloudflare

## Kurulum notları

API kimlik bilgileri `.env` dosyasında tutulur. Örnek için `.env.example` dosyasına bakın. `.env` asla commit edilmez.
